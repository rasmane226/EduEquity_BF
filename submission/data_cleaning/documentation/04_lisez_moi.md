# 04. Lisez-moi – Data Cleaning

## Présentation

La phase du Data Cleaning contient les dossiers tels que les scripts, les résultats et la documentation relatifs au nettoyage des données du projet EduEquity BF.

Les traitements ont été réalisés à partir du fichier statistique de la DGESS consacré à l'enseignement primaire au Burkina Faso.

## Organisation des dossiers

* `scripts/` : scripts Python utilisés pour le nettoyage, l'harmonisation et les contrôles.(Téléverser dans la partie code de l'espace Challenge)
* `results/cleaned_data/` : fichiers CSV nettoyés et destinés aux analyses.(Téléverser dans la partie données de l'espace Challenge)
* `results/quality_reports/` : rapports issus des contrôles de qualité.(Téléverser dans la partie donnée de l'espace Challenge)
* `documentation/` : documents décrivant les opérations et les règles appliquées.(Téléverser dans la partie documentation de l'espace Challenge)

## Utilisation

Les scripts permettent de reproduire les opérations de nettoyage et d'harmonisation à partir du fichier Excel original.

Les fichiers du dossier `cleaned_data/` constituent les données finales de cette phase. Ils seront utilisés dans les étapes suivantes du projet.

Les rapports de contrôle permettent de consulter les résultats des vérifications effectuées.

## Source des données

Les données originales proviennent de la Direction générale des études et des statistiques sectorielles (DGESS) du Burkina Faso.
