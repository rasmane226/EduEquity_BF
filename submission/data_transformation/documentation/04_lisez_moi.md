# 04. Lisez-moi – Data Transformation

## Présentation

La phase du Data Transformation contient les dossiers regroupant les scripts, les résultats et la documentation relatifs à la transformation des données du projet EduEquity BF.

Les traitements ont été réalisés à partir des fichiers nettoyés lors de la phase précédente du projet.

## Organisation des dossiers

- scripts/ : scripts Python utilisés pour la préparation, la fusion et les contrôles qualité des données. (Téléverser dans la partie code de l'espace Challenge)
- results/transformed_sheets/ : onze fichiers CSV contenant les données transformées. (Téléverser dans la partie données de l'espace Challenge)
- results/merged_data/ : cinq tables analytiques regroupant les données transformées. (Téléverser dans la partie données de l'espace Challenge)
- results/quality_reports/ : quatre rapports issus des contrôles de validation et de qualité. (Téléverser dans la partie données de l'espace Challenge)
- documentation/ : documents décrivant le processus et les règles de transformation ainsi que les contrôles effectués. (Téléverser dans la partie documentation de l'espace Challenge)

## Utilisation

Les scripts permettent de reproduire les opérations de préparation, d'harmonisation et de fusion à partir des fichiers nettoyés.

Les fichiers du dossier transformed_sheets/ contiennent les données transformées individuellement. Les tables du dossier merged_data/ constituent les données analytiques préparées pour les étapes suivantes du projet.

Les rapports de contrôle permettent de consulter les résultats des vérifications effectuées.

Les données de ce dossier constituent les données préparées pour la phase suivante du projet : l'analyse exploratoire et statistique des disparités dans l'enseignement primaire au Burkina Faso.

## Source des données

Les données utilisées proviennent de la phase de Data Cleaning, réalisée à partir du fichier statistique de la Direction générale des études et des statistiques sectorielles (DGESS) du Burkina Faso.
